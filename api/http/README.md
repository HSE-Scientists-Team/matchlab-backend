# HTTP API Gateway

[`openapi.yaml`](openapi.yaml) описывает текущие публичные маршруты Gateway, примеры JSON-запросов и ответов, ошибки и Bearer-авторизацию. Scalar показывает эту спецификацию как интерактивную документацию. Это описание фактически реализованного API, а не будущих сценариев продукта.

Для локального запуска выполните из корня репозитория:

```sh
docker compose up --build
```

Откройте `http://localhost:8084` (порт можно изменить переменной `API_DOCS_PORT`). Документация и API доступны в браузере на одном адресе: контейнер документации проксирует `/api/v1/*` и `/health` в Gateway. Поэтому кнопка отправки запроса в Scalar работает без настройки CORS. Порт документации привязан к `127.0.0.1`; в продакшене его публикацию и контроль доступа нужно настраивать отдельно.

Для проверки сценария зарегистрируйтесь, войдите, затем укажите полученный `access_token` в Bearer Auth интерфейса Scalar. Вызовите `POST /api/v1/users/me/email`, откройте письмо в Mailpit по адресу `http://localhost:8025` и скопируйте токен из ссылки в `POST /api/v1/auth/email/confirm`. Примеры в спецификации содержат учебные значения и не являются действующими токенами.

Исходники интерфейса Scalar не загружаются с CDN при открытии страницы: при сборке Docker-образа берётся зафиксированная версия браузерного бандла, проверяется её контрольная сумма и файл обслуживается локально. При изменении HTTP-маршрута, схемы или кода ответа обновляйте `openapi.yaml` вместе с Gateway.
